📱 APK Builder Tools

Generator helper untuk pengembangan Android — AndroidManifest, launcher icon set, strings.xml, colors.xml, permission picker, dan build.gradle snippet. Cocok dipakai sebelum build APK di Android Studio.

Pilih Tool

📄 AndroidManifest.xml Generator

Isi form di bawah untuk menghasilkan AndroidManifest.xml lengkap dengan application + main activity.
