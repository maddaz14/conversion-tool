🌐 Multi Language Tools

Utilitas i18n / l10n untuk developer — kelola translation key dengan editor side-by-side, merger, missing key finder, CSV ↔ JSON, key extractor dari source code, dan referensi kode locale BCP-47.

Pilih Tool

📝 i18n JSON Editor

Kelola translation key untuk beberapa bahasa sekaligus dalam tabel. Tambahkan kolom bahasa, isi terjemahan, lalu export tiap bahasa sebagai JSON.

🧬 i18n Merger

Gabungkan beberapa file JSON i18n menjadi satu. Berguna saat hasil terjemahan tim datang dalam potongan terpisah.
